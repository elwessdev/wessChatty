# WessChatty 💬

WessChatty is a real-time chat application built with the **MERN stack**

## ✨ Features
- 🔐 **Secure Authentication** using JWT (Access & Refresh Tokens).
- ⚡ **Real-Time Messaging** powered by WebSockets.
- 🤖 **ChattyAI** - A fixed chatbot available for all users.
- 🎨 **Modern UI** with responsive design.
- 🚀 **Fast & Scalable** architecture with MERN stack.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Real-time Communication:** WebSockets
- **Authentication:** JWT (Access & Refresh Tokens)
